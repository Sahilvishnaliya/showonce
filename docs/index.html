ShowOnce documentation

ShowOnce teaches a robot arm a pick-and-place task from one human demonstration. SAM 3.1 tracks objects through the demo, the system infers the rule behind it, Muse Wonder compiles the program, the robot repeats it on a rearranged bench, and vision verifies the result.

The loop

  1. Demonstrate — do the task once. Objects are tracked as SAM masks → centroids (tracks).
  2. Learn — POST /api/learn {tracks, bins} infers the rule (e.g. colour → matching bin) and emits a pick-and-place program with a confidence score.
  3. Repeat — POST /api/plan {objects, bins, program} plans from live positions; a 2-link IK arm executes.
  4. Verify — POST /api/verify {objects, bins} checks every object against the rule and scores the run.

Live camera

POST /api/segment-live {image, prompts} segments a real bench frame with SAM 3.1 (one request per prompt), parses Meta's wire format, and decodes masks with the official meta_sam_parser. Requires MODEL_API_KEY + SECONDNURSE_MODE=live on the server; without them it returns 503 — results are never invented.

Why it generalizes

The learner records rules, not positions. Planning reads current object coordinates at run time, so a shuffled bench is the normal case. Verification is geometric: an object is correct exactly when its centre is inside the bin of its own colour.

Scope

ShowOnce ships with a simulated arm so the full loop runs anywhere; the learned program is plain JSON pick-and-place for a real controller to consume. It is a robotics teaching system, not a safety-rated industrial controller.
